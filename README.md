# DevForge - Next-Gen Learning Platform

A premium, AI-powered coding learning platform built with Next.js 15, TypeScript, Firebase, and Tailwind CSS.

## Features
- Immersive 3D/Aurora Landing Page
- Personalized Student Dashboard
- Problem Solving & Code Editor
- Role-based Admin Management

## Deployment
This project is configured for Firebase Hosting.

### Environment Variables
Create a `.env.local` file with the following Firebase credentials:
- `NEXT_PUBLIC_FIREBASE_API_KEY`
- `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`
- `NEXT_PUBLIC_FIREBASE_PROJECT_ID`
- `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET`
- `NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID`
- `NEXT_PUBLIC_FIREBASE_APP_ID`

## Build
```bash
npm run build
```
